# Project locks

1. Slime Life is independent from Colony Clash. Never edit or depend on `wisteria477/colony-clash`, its Supabase project, Cloudflare deployment, branches, assets, or secrets.
2. Native app/game only. A browser mockup is not the product.
3. First playable scope: one house; build; create slime; add slime; baby; autonomous indefinite household simulation.
4. No old-age death in this milestone.
5. UI must have its own Slime Life identity and must not copy The Sims UI, plumbob, panels, portrait rails, or mode layout.
6. `assets/models/nim_slime_current.glb` is replaceable; gameplay code must not depend on a specific mesh hierarchy beyond optional material tinting.
